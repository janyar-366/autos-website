# Auto Website

## Over het project

Dit project is een website waarop verschillende auto's worden weergegeven met een afbeelding en informatie, zoals het vermogen en het bouwjaar.

## Doel

Het doel van deze opdracht is om de website uit te breiden door **Drie nieuwe auto's** toe te voegen. Elke auto krijgt een afbeelding en informatie, zodat bezoekers meer auto's kunnen bekijken.

## Gebruikte technieken

* HTML
* CSS
* Visual Studio Code
* git

## Wat is toegevoegd?

* 4 nieuwe auto's.
* Voor elke auto een afbeelding.
* Informatie zoals de naam, het vermogen (PK) en het bouwjaar.
* De auto's worden netjes weergegeven in dezelfde stijl als de bestaande auto's
